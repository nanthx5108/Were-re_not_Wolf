# Morning event assets

These images are served as `/events/<filename>` and are referenced by the morning event system.

Canonical active files:
- `blackout.png`
- `boat_return.png`
- `bonfire.png`
- `circling_crow.png`
- `distant_howl.png`
- `fog.png`
- `full_moon.png`
- `high_tide.png`
- `warning.png`

Legacy `Situation-*` variants and other duplicates are archived in `_archive/` and should not be used by runtime code.
