# Role card assets

Runtime assets used by the game are stored directly in this folder and served as `/roles/<filename>`.

Canonical active files:
- `back.png` — role-card back
- `bodyguard.png` — Bodyguard card
- `fool.png` — Fool card
- `seer.png` — Seer card
- `silencer.png` — Silencer card
- `villager.png` — Villager card
- `werewolf.png` — Werewolf card

Keep the filenames exactly as above. Any extra copies or legacy variants should live under `_archive/` and must not be used in runtime paths.
